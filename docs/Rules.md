# DormDrop Coding Rules

## React

Use Functional Components only.

Use Hooks only.

Never use Class Components.

---

## Styling

Tailwind CSS only.

Avoid inline styles.

Maintain consistent spacing.

---

## State

Lift shared state to the nearest common parent.

Avoid duplicated state.

---

## Components

Keep components focused.

Split large components into reusable ones.

---

## Backend

Controllers contain business logic.

Routes only define endpoints.

Models only define schemas.

Never mix responsibilities.

---

## Naming

camelCase

PascalCase for Components

Meaningful variable names.

---

## Async

Use async/await.

Avoid .then() chains.

---

## Error Handling

Always handle API errors.

Show user-friendly toast messages.

Never leave empty catch blocks.

---

## AI Instructions

Do not redesign the UI unless requested.

Preserve project architecture.

Explain concepts before writing code.

Build incrementally.

Avoid unnecessary libraries.
